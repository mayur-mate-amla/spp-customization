## The logger (packages/logger/src/log-manager/server-logger.ts)
  log(): push to an in-memory buffer; every 10th entry flushes the buffer (logThreshold = 10, config/index.ts)
  flush: POST {WEBSTORE_DOMAIN_NAME}/api/send-log-to-file -> appends to logs/logs-<date>.txt (or Znode API with LOGGING_METHOD=API)
  each server module has its own buffer: the sandbox crash at 11:59:36 reached the file at 12:29
